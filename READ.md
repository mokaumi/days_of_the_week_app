# 🗓️ Days of the Week with Notes

This is a simple, colorful JavaScript web app that displays the days of the week and allows users to add and save notes for each day. Notes are saved in the browser using localStorage, so they persist even after refreshing the page.

## 🚀 Features
- Highlights the current day of the week.
- Textarea for writing notes under each day.
- Save button to store daily notes in `localStorage`.
- Clean and responsive design.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser `localStorage`
